# Blockchain: от новичка до профессионала 

Курс лекций по блокчейну в формате Markdown для [Obsidian](https://obsidian.md/) — от базовых понятий до продвинутых тем. Материал рассчитан на последовательное изучение: от «что такое блокчейн» до разработки смарт-контрактов, криптографии и архитектуры децентрализованных систем.
