Приложение, которое:
1. Берет Legacy-адрес в Bitcoin (testnet4)
2. Формирует новую транзацию
3. Подписывает транзакцию приватным ключом
4. Валидирует транзакцию
5. Отправляет транзакцию в тестовую сеть через публичный веб-сервис
6. Находит отправленную транзакцию в блокчейн-эксплорере

Запуск:
npm install bitcoinjs-lib ecpair tiny-secp256k1 bip32
node index.js <address> <sum> [--dry]
