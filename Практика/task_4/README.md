1. Приложение, которое:
- Имитирует ключ некастодиального кошелька их формата xpriv или seed-фразы
- Перебирает адреса в сети testnet4 для кошелька
- Находит ключ от адреса, с которого можно потратить деньги

2. Приложение, которое:
- Компилирует транзакцию с SegWit адреса в тестовой сети
- Подписывает ее с помощью импортированного из некастодиального кошелька ключа
- Валидирует и отправляет транзакцию в testnet4

Запуск:
npm install bitcoinjs-lib ecpair tiny-secp256k1 bip32 bip39
node index1.js
node index2.js
